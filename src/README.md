# Source code

This directory is reserved for reusable Python source code supporting the project.

For this academic project, the complete executable analysis and modelling workflow is maintained in the final notebook:

`notebooks/Valerie_Andoulsi_Capstone_Machine_learning_based_network_intrusion_detection.ipynb`

The notebook contains:

- data preparation and preprocessing;
- exploratory data analysis;
- feature engineering;
- feature selection;
- PCA analysis;
- model development;
- cross-validation;
- hyperparameter tuning;
- threshold analysis;
- independent test evaluation;
- model explainability;
- bias and fairness analysis;
- final model configuration.

The final trained model and its configuration are stored separately in the `models/` directory.

## Deployment scope

Model deployment was considered outside the scope of this academic project.

No production API, real-time inference service, monitoring system or SOC integration was implemented.

The project focuses on model development, evaluation, explainability and reproducibility using the UNSW-NB15 dataset.
