# Reports

This directory contains the formal and complementary documentation produced for the project.

- `EDA_and_Feature_Engineering_Report.pdf` — formal EDA and feature engineering report.
- `EDA_and_Feature_Engineering_Report.html` — interactive web version.
- `UNSW-NB15_Data_Dictionary.pdf` — formal data dictionary.
- `UNSW-NB15_Data_Dictionary.xlsx` — reusable spreadsheet version of the data dictionary.
- `UNSW-NB15_Data_At_A_Glance.pdf` — one-page visual summary.
- `UNSW-NB15_Data_At_A_Glance.png` — visual summary for web and presentation use.
